📱 Sobre o Projeto

MovCine MZ é um aplicativo Android focado em entretenimento e conteúdos audiovisuais, desenvolvido com o objetivo de oferecer aos utilizadores uma experiência moderna, simples e intuitiva.

O projeto está em constante evolução, recebendo melhorias, novos conteúdos e atualizações para proporcionar uma experiência cada vez melhor.

---

✨ Funcionalidades

- 🎬 Catálogo de conteúdos
- 📺 Filmes e séries
- ▶️ Reprodução de vídeos com ExoPlayer
- 🔎 Navegação simples e intuitiva
- 🚀 Melhorias de desempenho
- 🆕 Atualizações frequentes
- 📱 Interface adaptada para dispositivos Android
